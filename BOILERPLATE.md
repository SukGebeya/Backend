# Go Boilerplate - Agent Guide

This document provides a comprehensive overview of the Go Boilerplate codebase for AI agents starting new projects from this template.

## Overview

A production-ready Go REST API boilerplate with:
- Clean Architecture (Handler→Service→Repository pattern)
- JWT authentication with RSA-signed tokens (access + refresh)
- PostgreSQL with sqlc for type-safe SQL
- Redis for refresh tokens and rate limiting
- Argon2id password hashing
- Soft delete for notes
- Docker-ready with multi-stage builds

## Architecture Flow

```
HTTP Request↓
Middleware (Auth, RateLimit, Timeout, Logging)↓
Handler (Parse request, validate, call service)↓
Service (Business logic, orchestration)↓
Repository (Data access, DB operations)↓
Database (PostgreSQL/Redis)
```

## Key Files to Understand

### Entry Point (`cmd/api/main.go`)

1. Loads configuration from environment
2. Initializes logger
3. Connects to PostgreSQL and Redis
4. Runs database migrations automatically
5. Creates repositories, services, JWT manager
6. Sets up HTTP router with middleware
7. Starts server with graceful shutdown

### Configuration (`internal/config/config.go`)

All config via environment variables:
- `PORT` - Server port (default: 8080)
- `ENVIRONMENT` - development/production
- `DATABASE_URL` - PostgreSQL connection string
- `REDIS_URL` - Redis connection string
- `JWT_*` - JWT key paths and TTLs
- `ARGON2_*` - Password hashing params
- `RATE_LIMIT_*` - Rate limiting config
- `LOG_*` - Logging config

### Router (`internal/http/router.go`)

Uses chi router with middleware chain:
1. RequestID → RealIP → Timeout(30s) → Logging → Recoverer → CORS → RateLimit

Route groups:
- `/health` - Health check (public)
- `/api/v1/register`, `/login`, `/refresh`, `/logout` - Auth (public)
- `/api/v1/*` - Protected routes (requires Auth middleware)
- `/api/v1/users/*` - Admin routes (requires "admin" role)

### Domain Models (`internal/domain/`)

## Database Layer

### sqlc Workflow

1. Write SQL queries in `sqlc/queries/queries.sql`
2. Run `make sqlc-generate`
3. Generated code appears in `internal/db/`
4. Generated interfaces: `Querier` interface

### Creating a New Query

```sql
-- name: GetMyEntity :one
SELECT id, name FROM my_entity WHERE id = $1;
```

Run `make sqlc-generate` to generate Go code.

### Migrations

```bash
make migrate-create# Create new migration
make migrate-up           # Apply migrations
make migrate-down         # Rollback
```

Migration files in `migrations/` with `.up.sql` and `.down.sql` suffixes.

## Authentication Flow

1. **Register/Login** → Returns `access_token` (15min) + `refresh_token` (7 days)
2. **API Call** → Include `Authorization: Bearer <access_token>`
3. **Token Expired** → Use `POST /api/v1/refresh` with `refresh_token`
4. **Logout** → Invalidates refresh token in Redis

### JWT Keys

RSA key pairs stored in `keys/`:
- `access_private.pem` / `access_public.pem`
- `refresh_private.pem` / `refresh_public.pem`

Generate with: `make generate-keys`

### JWT Manager (`pkg/jwt/`)

```go
manager, _ := jwt.NewManagerFromFiles(privPath, pubPath, ...)
claims, _ := manager.Validate(token)
```

## Service Layer

### Pattern

Each domain has:
- Interface in `internal/service/interfaces.go`
- Implementation in `internal/service/<domain>_service.go`
- Mock in `internal/service/mocks/` (generated)

### Interface Verification

Services verify interface implementation at compile time:
```go
var _ Authenticator = (*AuthService)(nil)
```

### Using Services

```go
authService := service.NewAuthService(userRepo, refreshTokenRepo, jwtManager, passwordHasher, refreshTTL)
userService := service.NewUserService(userRepo)
noteService := service.NewNoteService(noteRepo)
```

## Repository Layer

### Interfaces (`internal/repository/interfaces.go`)

- `UserRepository` - User CRUD
- `NoteRepository` - Note CRUD with soft delete
- `RefreshTokenRepository` - Token storage in Redis
- `RateLimitRepository` - Rate limit counters in Redis

### Circuit Breaker Pattern

Redis repositories wrapped with circuit breaker:
```go
refreshTokenRepo := repository.NewCircuitBreakerRefreshTokenRepository(redisClient)
rateLimitRepo := repository.NewCircuitBreakerRateLimitRepository(redisClient)
```

Settings: 60% failure threshold, 30s timeout, 5 max requests in half-open.

## Adding a New Entity

1. **Create migration**: `make migrate-create`
2. **Write migration SQL** in `migrations/<name>.up.sql`
3. **Add domain model** in `internal/domain/<entity>.go`
4. **Write SQL queries** in `sqlc/queries/queries.sql`
5. **Generate sqlc code**: `make sqlc-generate`
6. **Create repository** implementing `internal/repository/interfaces.go`
7. **Create service** with interface in `internal/service/interfaces.go`
8. **Create handler** in `internal/http/handler/<entity>_handler.go`
9. **Register routes** in `internal/http/router.go`
10. **Generate mocks**: `make mocks`
11. **Write tests**
12. **Generate swagger**: `make swagger`

## Resilience Features

1. **Request Timeout**: 30s timeout middleware (returns 408)
2. **Connection Pool**: Max 25, Min 5, 1h lifetime, 30m idle
3. **Circuit Breaker**: For Redis, 60% failure threshold, 30s timeout
4. **Rate Limiting**: Redis-backed, configurable requests/window

## Common Patterns

### Handler Pattern

```go
func (h *Handler) GetMyEntity(w http.ResponseWriter, r *http.Request) {
    idStr := chi.URLParam(r, "id")
    id, err := uuid.Parse(idStr)
    if err != nil {
        response.BadRequest(w, "invalid ID")
        return
    }
    
    entity, err := h.service.GetByID(r.Context(), id)
    if err != nil {
        handleServiceError(w, err)
        return
    }
    
    response.OK(w, entity)
}
```

### Service Pattern

```go
func (s *Service) GetByID(ctx context.Context, id uuid.UUID) (*domain.Entity, error) {
    entity, err := s.repo.GetByID(ctx, id)
    if err != nil {
        return nil, errors.NotFound("entity not found")
    }
    return entity, nil
}
```

### Repository Pattern

```go
func (r *Repository) GetByID(ctx context.Context, id uuid.UUID) (*domain.Entity, error) {
    row, err := r.db.GetByID(ctx, id) // sqlc-generated
    if err != nil {
        if errors.Is(err, pgx.ErrNoRows) {
            return nil, errors.NotFound("entity not found")
        }
        return nil, errors.Internal("database error", err)
    }
    return &domain.Entity{...}, nil
}
```

## Code Style Notes

- Use `internal/errors` package for all error handling
- Use `pkg/response` for JSON responses
- Validate requests with `go-playground/validator`
- Log with structured logging (`pkg/logger`)
- Use context from request throughout the stack
